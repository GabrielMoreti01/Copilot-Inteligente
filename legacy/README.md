# Protótipo original preservado

Esta pasta contém cópias do main.py original, do arquivo Main com Markdown e dos módulos originais. É material histórico, não o ponto de entrada suportado.

Limitações históricas: emoção por palavras-chave, classe visual fixa, RF sem treino, listas em memória, distâncias aleatórias, captura no servidor e possível sobrescrita de fotos. O aplicativo atual está em copiloto_app/api.py e frontend.
